# 本地服务启动清单

以后只要说“启动服务”“服务挂了”“手机要测试”“web 端看看”这类话，先按这个清单检查端口，再把缺的服务启动起来。

## 必须检查的服务

| 服务 | 端口 | 用途 |
| --- | --- | --- |
| MySQL | 3306 | 主业务数据库 |
| Redis | 6379 | 缓存、会话、队列相关 |
| 后端服务 | 3001 | App 和后台管理接口 |
| 大逃杀 WebSocket | 7272 | 大逃杀游戏通信 |
| Gateway Register | 1236 | 大逃杀 GatewayWorker 注册服务 |
| 后台管理系统 | 3100 | 管理后台页面 |
| Flutter Web 预览 | 3200 | 需要 web 端预览 App 时再启动 |
| 本地 Nginx | 80 | 只在测试 APK 下载/检查更新时需要 |

## 检查命令

```powershell
$ports = 3306,6379,3001,7272,1236,3100,3200,80
foreach ($p in $ports) {
  $rows = netstat -ano | Select-String ":$p\s"
  if ($rows) { "PORT $p OK" } else { "PORT $p NOT_FOUND" }
}
```

## 启动命令

Redis：

```powershell
Start-Process -FilePath "D:\myApp\redis\redis-server.exe" -ArgumentList "D:\myApp\redis\redis.windows.conf" -WindowStyle Hidden
```

MySQL：

```powershell
Get-Service | Where-Object { $_.Name -match 'mysql|mariadb' }
Start-Service -Name <查到的MySQL服务名>
```

后端服务：

```powershell
Start-Process -FilePath "powershell.exe" -ArgumentList @(
  '-NoProfile',
  '-ExecutionPolicy',
  'Bypass',
  '-Command',
  'cd "D:\myApp\work_ycykj\jjyx\jjyx\server"; npm run start:dev'
) -WindowStyle Hidden
```

后台管理系统：

```powershell
Start-Process -FilePath "powershell.exe" -ArgumentList @(
  '-NoProfile',
  '-ExecutionPolicy',
  'Bypass',
  '-Command',
  'cd "D:\myApp\work_ycykj\jjyx\jjyx\admin"; npm run dev -- --host 0.0.0.0'
) -WindowStyle Hidden
```

大逃杀服务：

```powershell
Start-Process -FilePath "powershell.exe" -ArgumentList @(
  '-NoProfile',
  '-ExecutionPolicy',
  'Bypass',
  '-Command',
  '$env:PATH="D:\myApp\php;" + $env:PATH; cd "D:\myApp\work_ycykj\jjyx\jjyx\server\uploads\games\killer-server"; php windows.php'
) -WindowStyle Hidden
```

Flutter Web 预览：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run-flutter-web.ps1 -NetworkProfile lan -ApiHost <当前电脑局域网IP> -ServerPort 3001 -WebPort 3200
```

本地 Nginx：

```powershell
Start-Process -FilePath "D:\myApp\nginx\nginx.exe" -WorkingDirectory "D:\myApp\nginx" -WindowStyle Hidden
```

## 启动后的验证

```powershell
Invoke-RestMethod http://127.0.0.1:3001/api/app/version
Invoke-WebRequest http://127.0.0.1:3100/admin/ -UseBasicParsing
Test-NetConnection -ComputerName 127.0.0.1 -Port 7272
```

手机测试时，还要用当前电脑局域网 IP 验证：

```powershell
Invoke-RestMethod http://<当前电脑局域网IP>:3001/api/app/version
Test-NetConnection -ComputerName <当前电脑局域网IP> -Port 7272
```

## 注意

- 先查端口，缺哪个启动哪个，避免重复启动一堆进程。
- 手机 App 本地测试必须保证 APK 里的地址和当前电脑局域网 IP 一致。
- 大逃杀服务启动时必须把 `D:\myApp\php` 加进 PATH，否则会出现 `php is not recognized`。
- Nginx 只影响 APK 下载/检查更新，不影响普通接口和游戏测试。

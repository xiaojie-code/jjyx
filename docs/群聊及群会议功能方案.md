# 群聊及群会议功能落地方案

## 一、功能概览

| 模块 | 功能 | 参考 |
|------|------|------|
| 群聊天 | 文字/图片/语音消息、管理员管理 | 微信群聊 |
| 群会议 | 视频会议、屏幕共享、录制回放 | 腾讯会议 |
| 管理后台 | 会议管控、记录清理、数据管理 | 自研 |

## 二、群聊功能

### 2.1 基础聊天

| 功能 | 说明 |
|------|------|
| 文字消息 | 常规文字发送，支持表情 |
| 图片消息 | 调用手机相册选择图片发送，支持拍照 |
| 语音消息 | 长按录音发送 |
| 消息记录 | 所有聊天记录服务端保存，定期清除 |
| 消息清理 | 管理后台可配置保留天数（3天/7天/自定义） |

### 2.2 群管理

| 功能 | 权限 | 说明 |
|------|------|------|
| 创建群 | 所有用户 | 创建者自动成为群主 |
| 拉人入群 | 群主/管理员 | 自由拉人，无需对方同意 |
| 踢人出群 | 群主/管理员 | 被踢用户立即移出 |
| 禁言 | 群主/管理员 | 禁言后该用户无法发送消息 |
| 解除禁言 | 群主/管理员 | 恢复发言权限 |
| 设置管理员 | 群主 | 群主可指定/取消管理员 |
| 解散群 | 群主 | 群主可解散群聊 |
| 退出群 | 普通成员 | 自行退出 |

### 2.3 技术方案

```
客户端（Flutter）                    服务端（NestJS）
┌──────────────┐                ┌──────────────────┐
│ image_picker │ ── 选图/拍照 ──→│ 文件上传 API      │
│ 相册/相机    │                │ (OSS/本地存储)    │
└──────────────┘                └──────────────────┘
┌──────────────┐                ┌──────────────────┐
│ Socket.IO    │ ── 实时消息 ──→│ ChatGateway      │
│ 客户端       │                │ (WebSocket)      │
└──────────────┘                └──────────────────┘
```

**消息存储**：MySQL messages 表，定时任务按配置天数清理过期消息。

## 三、群会议功能

### 3.1 功能列表

| 功能 | 说明 |
|------|------|
| 发起会议 | 群主/管理员免费发起，普通用户消耗积分 |
| 加入会议 | 群成员自由进出，无需邀请 |
| 视频通话 | 调用手机前/后摄像头 |
| 音频通话 | 麦克风开关 |
| 踢出会议 | 管理员可踢出参与者，被踢后无法再进入本次会议 |
| 人数无上限 | 不限制参会人数 |
| 会议录制 | 自动录制，保存到管理端 |
| 强制关闭 | 管理后台可强行结束进行中的会议 |
| 回放记录 | 管理端可查看录制回放，定期清除（3/7天可配） |

### 3.2 发起权限

| 角色 | 权限 | 费用 |
|------|------|------|
| 群主 | 直接发起 | 免费 |
| 管理员 | 直接发起 | 免费 |
| 普通成员 | 需消耗积分 | 可配置（如100积分/次） |

### 3.3 技术选型

| 组件 | 方案 | 说明 |
|------|------|------|
| 实时音视频 | WebRTC + SFU 服务器 | 支持多人视频 |
| 信令服务 | Socket.IO | 复用现有 WebSocket |
| 媒体服务器 | mediasoup / Janus | 开源 SFU，支持大规模 |
| 录制 | 服务端录制（mediasoup-record） | 自动录制到服务器 |
| 存储 | OSS / 本地磁盘 | 录制文件存储 |
| 客户端 | flutter_webrtc 插件 | 调用摄像头/麦克风 |

### 4.3 定时清理任务

```typescript
// 每天凌晨2点执行清理
@Cron('0 2 * * *')
async cleanExpiredData() {
  const retentionDays = await getConfig('data_retention_days'); // 3或7
  const cutoff = new Date(Date.now() - retentionDays * 86400000);
  
  // 清理过期消息
  await messageRepo.delete({ createdAt: LessThan(cutoff) });
  
  // 清理过期录制文件
  const expired = await recordingRepo.find({ createdAt: LessThan(cutoff) });
  for (const r of expired) {
    await deleteFile(r.filePath);
    await recordingRepo.remove(r);
  }
}
```

## 六、依赖和注意事项

1. **mediasoup**：需要单独部署媒体服务器，对服务器带宽要求高
2. **flutter_webrtc**：Flutter Web 端支持有限，建议优先 Android/iOS
3. **录制存储**：视频文件较大，建议接入 OSS 云存储
4. **TURN 服务器**：NAT 穿透需要部署 TURN 服务器（如 coturn）
5. **积分消耗**：普通用户发起会议扣积分，需要在发起前校验余额
6. **被踢机制**：被踢用户的 userId 记录到 meeting_bans 表，加入时校验

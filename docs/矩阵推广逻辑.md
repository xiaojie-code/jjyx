# 矩阵推广逻辑

## 一、核心概念

矩阵推广以"7 人矩阵"为一个完整周期：1 个矩阵顶点用户 + 6 个下级位置。矩阵跑满后，顶点用户手动点击"进入下一轮"出局并开启下一轮矩阵。

| 概念 | 说明 |
|------|------|
| 矩阵顶点 | 当前矩阵的顶点用户，例如 A |
| 矩阵成员 | 进入 A 当前矩阵的 6 个下级位置，编号为 1-6 |
| 直推用户 | 注册时填写了 A 的邀请码的用户，is_direct = true |
| 补位用户 | 非 A 的直推，通过跟随链进入 A 矩阵的用户，is_direct = false |
| 跟随关系 | 直接推广关系形成后，用户长期跟随该上级，不因出局而断开 |
| 启动金额 | 每个用户资金金额，当前为 2000 |
| 出局 | 当前矩阵 6 个位置全部填满后，顶点用户可手动进入下一轮 |

## 二、矩阵结构

一个完整矩阵固定为 7 个账号，其中 A 是矩阵顶点，1-6 是下级位置。

```text
        A 的矩阵
        ┌─────────────────┐
        │        A        │  顶点
        │      /   \      │
        │     1     2     │  一层
        │    / \   / \    │
        │   3   4 5   6   │  二层
        └─────────────────┘
```

层级说明：

| 层级 | 位置 | 人数 |
|------|------|------|
| 顶点 | A | 1 人 |
| 第一层 | 1、2 | 2 人 |
| 第二层 | 3、4、5、6 | 4 人 |

## 三、排位规则

矩阵排位分两种场景：

### 场景一：在自己的矩阵中（直接上级是矩阵顶点）

顶点的直推用户按顺序填充，优先1、2号位，满了继续填3、4、5、6号位。

例如：用户1是矩阵顶点，直推了用户3、4、5。用户3进1号位，用户4进2号位，用户5进3号位。

### 场景二：向上补位到上级矩阵（严格树形限制）

| 入位用户的直接上级 | 可占位置 | 满了怎么办 |
|-------------------|----------|-----------|
| 1 号位用户 | 仅 3、4 号位 | 不能进入这个矩阵 |
| 2 号位用户 | 仅 5、6 号位 | 不能进入这个矩阵 |
| 第二层用户 | 不能进入 | — |
| 不在矩阵中 | 不能进入 | — |

**关键规则**：
- 1号位用户的直推只能进3、4号位。如果3、4都满了，不能溢出到5、6号位，只在自己的矩阵里排位
- 2号位同理，直推只能进5、6号位
- 收益始终归矩阵顶点，和中间层级用户无关

## 四、数据库字段

矩阵坑位表（matrix_slots）关键字段：

| 字段 | 说明 |
|------|------|
| id | 主键 |
| matrix_id | 所属矩阵ID |
| slot_number | 坑位编号（1-6） |
| user_id | 占位用户ID |
| is_new_user | 是否为新用户（第一轮） |
| is_direct | 是否为矩阵顶点的直推用户（true=直推，false=补位） |
| income_amount | 该坑位产生的收益金额 |
| income_type | 收益类型（claimable/next_fund/none） |
| reentry_count | 再次入位次数（用于递推计算） |

用户表关键字段：

| 字段 | 说明 |
|------|------|
| id | 用户ID，作为节点ID |
| invite_code | 邀请码，注册时生成的唯一邀请码 |
| invited_by | 被邀请码，注册时填写的上级用户ID（父节点ID） |

**is_direct 判断逻辑**：如果坑位用户的 invited_by 等于矩阵的 owner_id，则 is_direct = true，表示是顶点的直推用户；否则为 false，表示是通过跟随链补位进来的。

## 五、收益规则

收益按用户**实际资金**计算：

| 用户类型 | 资金来源 | 收益 | 说明 |
|---------|---------|------|------|
| 新用户（第1轮） | 固定 2000 | 2000 × 35% = 700 | 首次入位 |
| 老用户（第N轮） | 自己矩阵上一轮5、6号位收益之和 | startFund × 35% | 按实际资金计算 |

**启动资金计算**：
- 用户出局进入下一轮时，启动资金 = 自己矩阵5号位收益 + 6号位收益
- 例如：5、6号位都是新用户 → 启动资金 = 700 + 700 = 1400
- 用户进入上级矩阵时给上级带来的收益 = 自己的启动资金 × 35%
- 例如：启动资金1400 → 给上级收益 = 1400 × 35% = 490

收益分配：

| 坑位 | 收益归属 | 说明 |
|------|---------|------|
| 1、2、3、4 号位 | 顶点用户 A 可领取 | 直接收益 |
| 5、6 号位 | A 的下一轮启动资金 | 不可领取，带入下一轮 |

**注意**：
- 收益金额显示到小数点后 1 位（向下取整），≥ 0.1 才显示
- 实际金额累加保留完整精度
- 无论是直推用户还是补位用户，坑位收益计算方式相同，都归矩阵顶点

## 六、出局与下一轮

当 A 的当前矩阵位置 1-6 全部填满时，用户可手动点击"进入下一轮"按钮出局。

处理规则：

1. A 当前矩阵标记完成
2. 系统为 A 开启下一轮矩阵
3. A 出局后**再次进入**上级矩阵的空位（每次出局都会占一个新坑位）
4. 入位规则：按从上到下、从左到右找空位（1→2→3→4→5→6）

**级联入位规则**：
- 当用户进入上级矩阵的**第二层**（3-6号位）时，同时也要进入对应**一层用户的矩阵**
- 3、4号位 → 同时进入1号位用户的矩阵
- 5、6号位 → 同时进入2号位用户的矩阵
- 在一层用户的矩阵中，按顺序找空位（1→2→3→4→5→6）

**层级限制**：
- 用户在一层（1、2号位）时，其直推可以向上补位到上级矩阵的二层
- 用户在二层（3-6号位）时，其直推**不再**向上补位到上级矩阵

**示例**：
- 用户1在A矩阵1号位，出局后进入A矩阵5号位
- 5号位属于2号位的下层，所以用户1同时进入用户2的矩阵（找第一个空位）
- 用户1在用户2矩阵一层时，1的直推可以补位到用户2矩阵
- 用户1在用户2矩阵二层时，1的直推不再计入用户2矩阵

## 七、跟随原则与向上补位

1. 直推关系长期保留，不因出局而断开
2. 直推用户完成自己的矩阵出局后，会再次进入上级矩阵的空位
3. 新用户注册时进入直接上级的矩阵
4. **向上补位规则**：只有当直接上级在更上级矩阵的**第一层**（1、2号位）时，新用户才会向上补位到更上级矩阵
5. 如果直接上级在更上级矩阵的**第二层**（3-6号位），新用户不再向上补位
6. 每次出局后用户会在上级矩阵中占一个**新的**坑位（不是保留原来的位置）

## 八、并行矩阵

每个用户既可以是某个上级矩阵中的成员，也可以同时作为自己矩阵的顶点。

示例：

```text
A 的矩阵：          1 的矩阵：          3 的矩阵：
    A                   1                   3
   / \                 / \                 / \
  1   2               3   4               5   6
 / \ / \             / \                 / \ / \
3  4 5  6           5   6               ■ ■ ■ ■
```

- 用户 1 是 A 矩阵中的 1 号位成员
- 用户 1 同时是自己矩阵的顶点
- 用户 3 是 1 矩阵中的 1 号位，同时也在 A 矩阵的 3 号位（补位）
- 如果 1 再拉两个人（或 4 再拉两个人），1 的矩阵就完成了，1 可以进入下一轮

## 九、完整流程示例

1. A 开启第 1 轮矩阵
2. 用户 1 注册填写 A 的邀请码 → 进入 A 矩阵 1 号位（is_direct=true）
3. 用户 2 注册填写 A 的邀请码 → 进入 A 矩阵 2 号位（is_direct=true）
4. 用户 3 注册填写 1 的邀请码 → 进入 1 的矩阵 + 补位到 A 矩阵 3 号位（is_direct=false）
5. 用户 4 注册填写 1 的邀请码 → 进入 1 的矩阵 + 补位到 A 矩阵 4 号位（is_direct=false）
6. 用户 5 注册填写 3 的邀请码 → 进入 3 的矩阵 + 补位到 1 的矩阵
7. 用户 6 注册填写 3 的邀请码 → 进入 3 的矩阵 + 补位到 1 的矩阵
8. A 矩阵位置 1-6 全部填满
9. A 点击"进入下一轮"，出局，开启第 2 轮矩阵
10. A 检查自己的上级矩阵，如果有空位则入位

## 十、规则汇总

| 规则项 | 规则 |
|--------|------|
| 矩阵人数 | 固定 7 个账号：1 个顶点 + 6 个下级 |
| 排位方式 | 树形结构，直推优先占对应位置 |
| 出局方式 | 手动点击"进入下一轮"按钮 |
| 收益计算 | 每个坑位 = 用户资金基数 × 35%，按轮次递推 |
| 1-4 号位收益 | 顶点用户可领取 |
| 5-6 号位收益 | 作为下一轮启动资金，不可领取 |
| is_direct | 标记该坑位用户是否为顶点的直推用户 |
| 跟随原则 | 直推用户完成自己的矩阵后继续跟随上级 |
| 向上补位 | 新用户注册时，如果直接上级在更上级矩阵中（作为新用户），则向上补位 |

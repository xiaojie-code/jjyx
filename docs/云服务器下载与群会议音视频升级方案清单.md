# 云服务器下载与群会议音视频升级方案清单


当前项目不建议再单独购买一台普通云服务器来承载 APK 下载和群会议音视频。

推荐方案
手机 App
├─ API / WebSocket

│
├─ APK 下载 / 图片 / 文件
│  └─ 腾讯云 COS + CDN
│
└─ 群会议音视频 / 录制
   └─ 腾讯云 TRTC + 云端录制
      └─ 录制文件存 COS 或 VOD

群会议音视频与录屏方案

### 推荐 TRTC，不建议自己搭 TURN/SFU

当前项目已有：

- Flutter App。
- NestJS 后端。
- Socket.IO 聊天和会议信令。
- 群会议基础业务表。
- 管理后台会议记录和回放入口。

下一步不要继续在现有 P2P WebRTC 上硬扛多人会议。推荐把媒体层切换到腾讯云 TRTC：

- 后端继续负责登录、群权限、会议创建、群主/管理员控制、会议记录。
- TRTC 负责音视频采集、发布、订阅、弱网、NAT 穿透、多人会议媒体转发。
- 云端录制负责会议录屏。
- 录制文件存 COS 或 VOD。

### 与当前项目功能的结合方式

保留现有业务逻辑：

| 当前功能 | 调整方式 |
|----------|----------|
| 群主/管理员开启会议 | 后端创建会议记录，并生成 TRTC 房间参数 |
| 普通成员加入会议 | 后端校验群成员身份后返回 TRTC UserSig |
| 麦克风默认关闭 | App 进入会议后默认不 publish 音频，用户手动打开 |
| 摄像头默认关闭 | App 进入会议后默认不 publish 视频，用户手动打开 |
| 只允许一个摄像头画面 | 后端维护 `active_video_user_id`，已有用户开摄像头时提示“已有用户正在分享画面，请稍等” |
| 会议录制 | 会议开始时按配置开启 TRTC 云端录制，结束后保存 `recording_url` |
| 后台强制结束会议 | 后端结束会议并通知 App 退出 TRTC 房间 |

### TRTC 费用估算

TRTC 的音视频时长按进入房间后的音频/视频订阅时长计费，视频按分辨率分档。官方当前后付费示例：

| 类型 | 单价 |
|------|------|
| 音频 | 0.99 美元 / 千分钟 |
| 高清 HD，最高 1280x720 | 3.99 美元 / 千分钟 |
| 全高清 Full HD，最高 1920x1080 | 8.99 美元 / 千分钟 |
| 2K | 15.99 美元 / 千分钟 |
| 4K | 35.99 美元 / 千分钟 |

腾讯云 TRTC 当前还有包月套餐：

| 套餐 | 价格 | 赠送音视频通话时长 | 适合场景 |
|------|------|--------------------|----------|
| 入门版 | 0 元 | 无套餐赠送，按量/免费额度 | 开发测试、灰度测试 |
| 基础版 | 625 元/月 | 11 万分钟/月 | 小规模正式运营 |
| 尊享版 | 1875 元/月 | 38 万分钟/月 | 用户量稳定增长 |
| 旗舰版 | 6250 元/月 | 140 万分钟/月 | 大规模会议和运营 |

测试阶段建议：

1. 先开 TRTC 入门版。
2. 领取或使用可用免费时长。
3. 后台设置预算告警，例如 100 元、300 元、500 元三级提醒。
4. 真机验证稳定后，再决定是否购买基础版。

正式早期建议：

- 如果每月会议总时长低于 10 万分钟，先使用入门版 + 按量/免费额度观察账单。
- 如果每月会议总时长稳定超过 10 万分钟，购买基础版更容易控制成本。
- 如果需要 AI 降噪、页面录制、弱网增强等高级能力，再评估尊享版或 Plus 套餐。

## 五、会议录制费用说明

云端录制不是只收一项费用，通常会包含：

| 费用项 | 说明 |
|--------|------|
| TRTC 云端录制用量 | 录制机器人进入房间并订阅媒体流，会产生录制相关用量 |
| 音视频时长 | 录制机器人订阅音视频流也可能产生时长费用 |
| 存储费用 | 录制文件保存到 VOD 或 COS 后产生存储费用 |
| 播放/下载流量 | 后台或 App 播放回放、下载回放时产生下行流量 |
| 转码费用 | 如果需要转 MP4、合流、生成更适合播放的格式，会有转码费用 |

小规模正式运营

假设：

- APK 每月 1000 次下载。
- 图片、文件流量较少。
- 群会议每月 5-10 万分钟以内。1w分钟约166.7小时
- 录制只保留 3-7 天。

| 项目 | 预算 |
|------|------|
| COS | 10-50 元/月 |
| CDN 500GB 或 1TB | 约 80-165 元/月 |
| TRTC 入门版按量或基础版 | 约 100-625 元/月 |
| 录制和存储 | 约 50-300 元/月 |
| 合计 | 约 300-1000 元/月 |



### 用户量增长后

假设：

- APK 每月 5000-10000 次下载。
- 图片和文件访问量增加。
- 群会议每月 10-40 万分钟。
- 录制回放访问增加。

| 项目 | 预算 |
|------|------|
| COS | 50-300 元/月 |
| CDN 1TB-5TB | 约 156-804 元/月 |
| TRTC 基础版或尊享版 | 625-1875 元/月 |
| 录制、转码、存储、回放 | 300-1500 元/月 |
| 合计 | 约 1000-4000 元/月 |

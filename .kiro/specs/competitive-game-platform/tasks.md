# 竞技游戏平台 - 开发任务清单

## 技术栈
- App端：Flutter（Dart）
- 后端：NestJS（TypeScript）
- 管理端：Vue3 + Element Plus
- 数据库：MySQL + Redis
- 游戏端：Cocos Creator（现有H5游戏换皮）
- 通信：WebSocket（IM）+ RESTful API + JSBridge（App↔H5）

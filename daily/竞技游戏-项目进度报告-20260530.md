## 当前可能存在的问题

### 1. 大逃杀服务端跑不了
大逃杀是联网对战游戏，必须连 PHP 服务端，而这个服务端用了 Linux 才有的功能，Windows 跑不起来。前端能加载但进不去游戏，目前设为维护状态。要么部署到 Linux，要么 Windows 上装 WSL。

### 2. 群会议只能小规模
现在是 P2P 模式，2-3 人没问题，人多了手机扛不住。要支持多人得上 SFU 媒体服务器，但 mediasoup 只能跑 Linux，Windows 服务器搞不定。

### 3. 跨网络视频可能连不上
没部署 TURN 服务器，同一个 WiFi 下能视频，但跨运营商、跨网络大概率连不上。

### 4. 服务器选型问题
现在打算用 Windows 服务器，但大逃杀 PHP 和群会议 SFU 都依赖 Linux。建议要么换 Linux 服务器，要么 Windows 上装 WSL 跑这两块。

### 5. H5 游戏的 JSBridge 还没真机联调
游戏能打开，但游戏里扣积分、结算、余额同步这些跟 App 的交互还没在真机上完整测过。

### 6. 本地 IP 会变
电脑连 WiFi 是动态 IP，每次可能变（73 变 74），打包前要确认当前 IP，建议在路由器里绑定固定 IP。

## 下一步建议

1. 先定服务器：如果要群会议多人 + 大逃杀，建议上 Linux（或 Windows + WSL）。
2. 把项目部署到服务器，换成公网地址重新打包测试。
3. 群会议加诊断面板，做电脑 Web + 两台手机的三端联调，先把 P2P 跑稳。
4. P2P 稳了再上 SFU（mediasoup）+ TURN（coturn），做多人会议。
5. H5 游戏 JSBridge 真机联调，重点测扣积分、结算、余额同步。

总的来说，功能基本都齐了，现在卡点主要在服务器环境（Linux 依赖）和真机联调上。把服务器定下来部署好，剩下的就是联调和打磨。

# 竞技游戏平台 - 项目进度报告

**日期**：2025.05.26

---

## 今天完成的

### 1. 矩阵收益计算逻辑修正（重要）
- 老用户收益不再用"2000×0.65的N次方"公式
- 改为：收益 = 用户自己矩阵上一轮5、6号位收益之和（startFund）× 35%
- 例如：5、6号位都是新用户 → startFund=1400 → 给上级收益=490
- 后端金额存储改为完整精度（DECIMAL 16,8），不截断不四舍五入
- 前端显示向下取整到0.1（不四舍五入）

### 2. 激活码功能
- 新用户注册后不再自动入位矩阵
- 需要先使用激活码激活才能开启矩阵和进入推广奖励
- 目前模拟激活码：输入 666666 即可激活
- 正常CDK激活也支持触发矩阵入位
- 前端进入推广奖励页面时检查激活状态，未激活弹窗提示

### 3. 级联入位逻辑
- 用户进入上级矩阵第二层（3-6号位）时，自动同时进入对应一层用户的矩阵
- 新用户注册时，如果直接上级在别人矩阵的一层，也会自动补位到那个矩阵

### 4. 点击顶点查看启动资金
- 点击"我 顶点"节点显示当前轮次和上轮带入的启动资金

### 5. 点击坑位用户显示详情
- 显示账号、昵称、坑位、上级用户、类型（新/老用户）、当前轮次、当前资金

## 已知问题

1. **历史数据不一致**：之前用旧公式生成的收益数据需要手动修正，新数据是正确的
2. **级联入位递归**：多层级联可能产生性能问题（A→1→3→5 这种深度链）
3. **startFund为0的情况**：首轮用户 startFund=0，`calculateSlotIncomeByRound` 会 fallback 到 2000，但如果用户激活后没有完成第一轮就不一定对
4. **同一矩阵多次入位**：用户可以在同一个上级矩阵占多个坑位，数据库的唯一约束需要确认已移除

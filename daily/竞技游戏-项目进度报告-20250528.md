## 今天做了什么

- 总收益只统计已完成矩阵的收益（进行中的不算）

### 4. 提现功能完善

- 重写了提现页面：显示可提现余额、金额选择（100的整数倍）、支付方式选择（支付宝/银行卡）、收款信息填写

- 加了 20% 手续费逻辑，按钮显示实际到账金额

- 加了提现记录列表，显示每笔提现的状态（审核中/已打款/已驳回）
- 管理后台提现列表显示：提现方式、收款人、收款账号、手续费明细
- 提现余额计算：总收益 - 已提现（待审核+已通过），驳回后自动恢复

### 5. 管理后台时间格式统一

- 社交管理、推广管理中所有时间字段统一改为 `YYYY-MM-DD HH:mm:ss` 格式

### 6. 语音播放修复

- 后端静态文件服务加了 CORS 头和正确的 Content-Type，解决电脑端语音播放报错

- 语音消息手机端播放未验证

- 手机端 release 打包和签名

## 当前可能存在的问题

1. **手机端 IP 硬编码**：目前 `app_constants.dart` 中 API 地址硬编码为 `192.168.31.75:3001`，换网络环境需要改代码重新打包
2. **会议 WebRTC**：局域网内 P2P 可能需要 STUN 服务才能穿透，公网需要 TURN 中继
3. **提现余额计算**：依赖 `matrix_incomes` 表的 SUM 查询，数据量大时可能慢，后续考虑加缓存字段
4. **矩阵自动出局**：改回自动出局后，如果 `handleMatrixComplete` 中有异常，可能导致入位事务失败
5. **多设备登录**：Socket `onlineUsers` 只存一个 socketId，同一用户多设备登录会互踢

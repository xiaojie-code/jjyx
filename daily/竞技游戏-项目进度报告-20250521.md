# 项目进度报告 - 2025.05.21

## 项目概况

竞技游戏平台，包含三端：
- **server**：NestJS 后端，端口 3001
- **admin**：Vue3 管理后台，端口 3100
- **app**：Flutter 客户端（Web），端口 3200

---

## 今天完成的内容

### 1. 注册邀请码验证
- 后端 DTO 加了 `@Matches` 校验，邀请码必须是 8 位大写字母+数字
- 前端注册页加了本地格式校验，输入框自动转大写
- 修复了前端 API 客户端 `onError` 没有解析后端返回的中文错误信息的问题（之前所有 400/409 错误都显示"注册失败，请稍后重试"）

### 2. 矩阵推广逻辑修复（重点）
- **修复出局后跟随入位**：用户完成矩阵出局后，现在会自动作为老用户进入上级的矩阵
- **修复向上递归补位逻辑**：新用户注册时不再无条件向上递归补位到所有上级矩阵。现在只有当直接上级作为新用户在其上级矩阵中时，才继续向上补位
- 修正了数据库中的错误数据（7777/8888 不应该出现在 1234 的矩阵中）

### 3. 推广奖励页面增强
- 加了当前账号显示
- 点击"直推人数"弹窗显示直推用户列表（账号、完成轮数、当前进度）
- 点击"完成矩阵"弹窗显示每轮详情，展开看坑位用户，标注"直推"/"非直推"

### 4. 消息和联系人角标
- 新增 `BadgeProvider` 管理未读消息数和好友申请数
- 底部导航栏：消息 tab 显示数字角标，联系人 tab 有好友申请时显示红点
- 后端新增 `/api/social/badges` 接口

### 5. 好友申请页面重做
- 改为 Tab 页：收到的 / 发出的
- 收到的显示同意/拒绝按钮，发出的显示状态
- 后端新增 `getSentRequests` 接口
- 修复了 `joined_at` 字段没有默认值导致同意好友申请 500 的问题

### 6. 聊天界面优化
- 消息列表显示对方头像和昵称
- 聊天页面改为微信风格：灰色背景、左右头像、绿色/白色气泡、昵称显示
- 后端 `getConversations` 返回 `peerUser` 信息
- 后端 `getMessages` 返回 `sender` 信息

## 未完成/待优化

- 角标红点在某些场景下可能不显示（`loadBadges` 时机问题，需要进一步调试）
- 矩阵推广的"老用户出局后跟随入位"逻辑需要更多场景测试
- 聊天头像目前用的是默认图标，实际头像上传/展示还没完善
- Flutter 版本太旧（659 天没更新），web 调试连接不稳定
- Redis 没有配置持久化，重启会丢缓存数据

---

## 当前可能存在的问题

1. **矩阵逻辑边界情况**：多层嵌套的邀请链（A→B→C→D）在同时出局时的顺序问题，还没充分测试
2. **角标不显示**：`loadBadges` 可能在 token 还没设置好时就调用了，导致 401 被静默吞掉
3. **聊天页面新消息**：Socket 收到的新消息没有 sender 信息，头像和昵称会显示为默认值
4. **数据库 ID 不一致**：之前清过数据库，用户 ID 变了，如果有硬编码的地方可能会出问题
5. **Flutter web 模式限制**：web-server 模式没有热重载，每次改代码都要重启进程
